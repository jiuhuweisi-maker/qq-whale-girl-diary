# SurfCore attribution

The reviewed source mirrors and three-way adaptations in this directory derive from [Mieksido/surfcore](https://github.com/Mieksido/surfcore). The exact baseline commit is recorded in `version.mjs`; its MIT copyright and permission notice are preserved in [UPSTREAM-LICENSE](UPSTREAM-LICENSE).

Whale-specific compatibility code, tests, deployment scripts and changes are part of this repository. A fresh build also retains the upstream checkout's original license. Third-party dependencies retain their own package licenses; the lockfile pins the installed releases.
