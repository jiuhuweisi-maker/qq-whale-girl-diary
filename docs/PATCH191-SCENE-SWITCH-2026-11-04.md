# 191 · 私信、群聊和 B 站换场

鲸戒可以从任意已开放的 QQ 会话用 `qq_switch_scene` 选择主人的私信、已允许的群或 B 站。B 站会话用 `bili.mjs scene private` 或 `bili.mjs scene group` 去 QQ。多个群可选时先返回候选群。她也可以留在原地继续聊天，或看完后决定安静离开。

换场给目标会话一个自然开口的机会。目标回合使用自己的会话令牌、最近消息和发送工具。分享视频时可带公开 BV 号或标准视频链接。私信正文、源会话引用和账户资料保留在原场合。共用日记仍按其可见范围检索。工具区分排队、目标会话接到请求和真正发言，后者以目标发送回执为准。

主动机会提示由鲸戒自己选听众和话题。原生发送、额度和静音检查作用于目标。每个目标的换场请求有两分钟去重窗口，B 站待接请求也在两分钟后过期。同一次源工具调用只能尝试一次。

隔离测试覆盖 QQ 私信唤醒群、QQ 交给 B 站调度器、B 站回到 QQ、明确目标群、无权限拒绝、重复请求和预算保护。生产加载验证使用只读工具列表。真实发言是否符合语境，由平时的聊天确认。
