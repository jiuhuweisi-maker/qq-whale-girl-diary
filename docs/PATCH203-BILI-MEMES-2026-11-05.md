# 203 B站玩梗与略过机器人

主人补充评论里常有玩梗、接梗和反话，疑似机器人的楼可以略过，避免互回刷楼。共享表达核心整合了该偏好，调度器删除了强制聚拢与给鱼点赞的流程提示。

现有安装的B站配置将 fishGuard.gatherEnabled、forceGather 和 likeEnabled 设为 false。疑似机器人很多时仍有防刷屏检查，正常回应真人楼层沿用现有回复路径。新部署应在B站设置中关闭自动聚拢和鱼群点赞，采用同样的偏好。

离线验证包含 7 项共享表达、4 项B站实际提示组装、40 项运行时、36 项桥接和1项全新构建。部署后还用实际配置调用纯判定函数，验证即使有聚拢请求，自动目标仍为空且无批量点赞目标。真实评论口吻与真人身份判断继续依靠日常记录观察。
