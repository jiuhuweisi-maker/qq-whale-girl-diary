# patch111：私信消息归属与日常表达

私信原先把一批文字拼成一个段落，并默认引用末条消息；用户在问题后补一个表情时，回复正文可能仍在答问题，引用却挂在表情上。另有把“请你说这句”当成用户对她说的话、固定尾签和回避式岔题的表现。

## 修改

- 私信保留每条消息的顺序、边界和附件来源，沿用群聊已有的本轮引用选择协议。多条时不猜默认引用；模型明确选择后，验证为本轮发言者的有效正文消息才挂引用。纯表情仍进入上下文，单独发送表情时也仍能回应；混在正文批里不抢正文引用。引用带回的背景附件不把末条表情变成新的正文。
- 保留原始当前正文供判断话意，引用资料不冒充新请求。明确的待说台词另标说话者、受话者；澄清上一句话仍优先。没有强制复读台词，也不改变管理权限。
- 将日常表达要求整合回原聊天偏好：可爱、emoji、颜文字、小括号、表情包和吐槽保留，不把任何口头禅当固定尾签；普通聊天接感受，不自动转成建议。不能接时简短说清，不假装没懂、虚构故障或吊起期待后岔题。替换角色卡里原有的自动岔题措辞，未放宽内容边界。
