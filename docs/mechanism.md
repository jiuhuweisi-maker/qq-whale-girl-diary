# 收藏、见闻与识图机制

## QQ收藏与表情说明

原生QQ收藏现可写：`add_custom_face`添加、`delete_custom_face`删除、`modify_custom_face`改备注。完整复核用`fetch_custom_face_detail`，`count`至少2000；较小参数会截断，不能拿截断结果当全部收藏。接口不校验上传内容，调用前必须核实真实图片，不用垃圾字节测试。

主人让鲸戒收图、拿图时，目标是QQ表情收藏；旧图库不批量导入。已有收藏与主人备注不覆盖。只有真实成功回执及独立复核后才说已收藏。

图片识别说明存独立索引，按完整32位MD5关联，和QQ可发送收藏、旧图库各自保存。同步收藏不应删除说明，也不应凭说明自动添加收藏。未知或看不清保持不确定，原图上的文字不猜。

## B站与QQ

B站和QQ共用现有人物与口吻。公开观看、评分、评论从当前角色目录形成见闻；不将私信导入公开记忆。浏览标题、读取字幕、查看画面分开记录，不能编造完整观看。

分享需要内容确实相关、有可用链接并沿既有主动机会发送；不把“愿意分享”说成固定定时任务已经开启。只有明确提及主人的公开评论才附稳定身份映射，避免同名误认和每条评论乱@。

## 成本纪律

识图先核对已识别MD5，只补缺口；每批不超过25张，先持久化逐条结果再合并。用户指定GPT-6 Luna，不能悄悄改用Qwen或更贵模型。先做少量验证，失败不整批盲重跑。

DSH原交接规定识图单张不超过¥0.03、每批不超过¥0.8、整轮不超过¥20；这些是任务预算，不能假装已经测得实际成本。API计费与Codex套餐额度不可混算，无法取得实际账单时必须说明。QQ/B站全局费用顶0是主人另行决定，不借识图任务恢复旧¥1/¥5全局上限；现有单次Token、防刷屏、休息和投递保护保留。
