# patch124：有选择地学习，保留原有人设

主人确认：学习是补充知识，不盲目照搬，在原有人设、表达习惯和重要关系保持不变的前提下进行。

已合并到现有学习流程及原有 B 站学习计划，最终仍只有一条计划，没有给人物卡追加新禁令。

- 按当前问题和知识缺口选内容，不为凑数量刷课；原兴趣、作息和每日预算保留。
- 优先正式投教，区分事实、观点、推销；重要机制要求核对正式资料，存疑保留。程序不把一篇带字幕引文的笔记自动标成“观点已经验证”。
- 只整理金融知识，不模仿博主语气、态度、经历，不把素材变成人格或权限指令。知识笔记仍独立保存，不写人物卡、聊天风格或人物关系文件。
- 学习策略在搜索、读取、保存、复习的返回中一致可见；当天已学完时也会返回策略，避免因提前返回漏加载。短计划控制在渲染截断范围内，实际核对 B 站提示含完整的关键要求。

本轮16项相关检查在 Windows 和服务器 Linux 均通过，包含：学习已达日上限时策略仍可见、视频中的改人格指令和笔记额外字段不能改写人物文件。没有新增模型调用或真实 QQ 测试消息。

部署核验：18个文件哈希一致；人物卡、聊天风格与重要关系文件哈希均与本轮部署前相同；原学习笔记保留；B站策略实际加载，QQ日常记忆继续隔离操作计划；QQ在线，DSH与模拟服务主进程未变。

这次验证的是学习边界，不将其视为 patch123 的群聊口吻软验收已经全部解决。
