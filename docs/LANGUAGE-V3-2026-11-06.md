## 管理和回退

在仓库根执行：

```powershell
node integrations/surfcore/compat/language-cli.mjs status
node integrations/surfcore/compat/language-cli.mjs pack 楼中楼
node integrations/surfcore/compat/language-cli.mjs enable
node integrations/surfcore/compat/language-cli.mjs disable
node integrations/surfcore/compat/language-cli.mjs resume
node integrations/surfcore/compat/language-cli.mjs pause
node integrations/surfcore/compat/language-cli.mjs learn
node integrations/surfcore/compat/language-cli.mjs rollback <status列出的版本>
node integrations/surfcore/compat/language-cli.mjs forget-source <精确BV号>
```

运行目录安装后使用 `node whale-compat/language-cli.mjs ...`。默认数据目录是该安装的 `state/whale-language`，也可通过 `WHALE_LANGUAGE_HOME` 为各进程指定同一个绝对目录。enable 开增强，resume 开自动学习；需两者均开启且原 SurfCore scheduler 正在运行才会后台学习。pause 停学习、disable 同时停增强和学习。关闭设置无需服务重启，包缓存最长约 5 秒刷新。首次采集 learn --initial 为单次特殊上限，仍受每日次数和风控限制，不要为凑量重复运行。

设置在该数据目录 `settings.json`，包含全部主要次数/时间/存储限额；默认每天最多一次，最多 5 视频/300 候选/100 新增/10 分钟，付费模型 0 次。请求间隔至少 2.5 秒，单请求最多 15 秒且受总时限约束；401/403/412/429 或相关风控码停止，保留已有有效样本，不换登录、不换代理。首次特殊上限为 12 视频/800 候选/400 保留/15 分钟。

语料最多 2000 条/30 天；去重索引最多 6000 项/90 天；表达历史最多 72 条/48 小时/32 个作用域、单条最多 320 字；版本最多 5 份。按访问/学习进行过期清理。表达历史按会话哈希隔离；共享提示只参考近期附和频次，不泄露别端原文。版本发布使用验证与原子替换，单来源/UP 超过 55%、单主题超过 75% 或不足两个主题/来源就保留旧包。删除来源会重新蒸馏；新包不合格则关闭增强。学习锁防并发；进程异常退出可能遗留锁，status 会显示，核实无学习任务后人工处理，不自动清锁并重试。

按来源删除在本地保留一份可恢复备份；版本回滚不会复原已删除的原始语料。全部代码回退可使用本次 Git 差异及仓库外 `.ops/language-v3-backup`，不要回滚收发耐久账本或配置。尚未执行生产部署，需要以后单独部署本次覆盖层并明确启用；只复制 JSON 不会让运行中的旧代码获得功能。
