# 190 · QQ 日常看图预览

`qq_get_message_images` 默认用较轻的普通图片预览。PNG、JPEG 和 GIF 预览最长边为 384 像素，上限 12 KiB。内容复杂时会缩到更小的尺寸。已有小图可以直接返回。明确要求读小字或辨认截图细节时，工具传 `detailed=true`，使用此前较清晰的兼容路径。图片原件仍可用于后续读取。

取图继续走已有桥接接口。MCP 把下载及接口返回耗时和本地预览耗时分开记在诊断日志里，记录只有耗时、图片数量和模式。准备模型输入仍在工具进程里执行。

隔离测试覆盖模型预览、实际 MCP 工具、桥接、运行时和新装构建。合成样本通过轻量模式得到 256×192、8911 字节，细节模式得到 320×240、17310 字节。实际计费和首条回复耗时需要使用后续正常聊天观察。

已在空闲窗口备份部署，DSH 和桥重载一次。QQ 在线，在线工具注册了细节选项，五个启动指纹和 535 个文件的清单核对通过。验收使用隔离图片和只读工具列表，模型调用与真实测试消息均为 0。
