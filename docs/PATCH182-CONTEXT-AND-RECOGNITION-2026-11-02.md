# patch182：B站见闻、启动时序与表情说明持久化

接手基线为 DSH patch181（Git `e2da7c4`）。本次沿实际生效源码做差异修复，不运行旧 patch143 构建器覆盖现有服务。

## 已复现的问题与修改

- B站的公开观看、打分、评论记录已经按角色保存，QQ记忆生成器仍读取旧账号目录，因此实际简报只有少量动态。改为当前角色目录，补充观看记录，区分“只读标题”“读到字幕”“看过部分画面”；不能把元数据写成完整观看经历。私信文件不参与公开见闻。
- 公开评论正文含精确的主人昵称时，新增 `at_name_to_mid` 请求映射；普通评论不自动喊主人。平台是否产生提醒仍要以自然互动结果验收。
- B站流程提示不再强制每次醒来评论、聚拢；继续加载现有共享口吻，不另写一套人格，不改兴趣权重、额度与频率。原固定八时段群分享没有启用，本补丁不擅自开启。
- 更正评论工具的错误提示“emoji需转义”：Unicode emoji、颜文字和括号本来会原样编码进正文，不应被工具误导成不能使用。实际评论表单中的emoji保留检查已通过，提示更正后6项相关回归再过；没有修改发送参数或额外发测试评论。
- 插件异步启动桥前等待宿主网页端口监听，并合并同时到达的启动请求。保留 patch148 对未知状态不强杀的保护和已有冷启动等待。
- DSH旧识图写回把图库说明标成 `source=local`，而收藏加载器会将其归为QQ来源，随后完整收藏同步将它清除。新增独立只读 `state/sticker-recognition.json`，不再混入可发送收藏列表；模型视图按精确MD5附带说明，原消息、媒体顺序与回执链不改。
- 先恢复已经保存的识图结果和主人备注，不重新付费识别。纠正人物卡里仅一行已经过期的“收藏不可写”能力事实，其他身份、风格、关系与记忆不改。

## 收尾发现，不能混作已经修好

最后QQ登录、WS、DSH、基础账本完整性及心跳正常，原配置/风格/备注仍一致。完整收藏列表的重复读取出现超时，群历史接口也出现超时；已停止继续请求，未因这些错误重登QQ。347收藏的结论来自本轮稍早独立接口读取及随后实际同步验证，不冒称最后一次大列表请求成功。

自然群聊另出现两次发送回包超时，原151随后自行核销。本轮没有发送这些测试消息，也没有重发、手工清锁或改账；独立的内容哈希核对因历史接口超时未能完成，不能据核销就声称两条内容确实送达。审查还发现原151只按“本人、同会话、附近时间”匹配，缺少对应内容及唯一回执校验。这是独立后续修复项，本补丁没有临时更改出站协议；不能把49项既有检查当作此项通过。后续应先补“旁边另一条消息不能核销本条”的反例，再强化证明条件，不凭时间相近清账。

重复回复旧例只得到“同回合存在多次发送”的聚合证据，没有确证同文、同引用重复发送，因此没有增加会误伤正常分段的内容过滤器。两条未知投递继续保留锁定，不清账、不补发。B站风控退避不因本补丁重置，不为验收额外发公开内容。
