# patch123：话题逻辑、生成失败恢复与重要关系

处理“换题仍点评旧图”“查完行情后沉默”“群友被当陌生人”等问题。patch122 的基金名称与 B 站学习功能保留。

## 查到的实证

1. 上游唤醒提示每轮写着“可以装傻、已读乱回”，与认真接住问题的总纲冲突。已替换，最近来信按顺序标明当前话头，问号与催问沿引用及未答问题理解。
2. 当天私信确实执行过搜索和行情工具，但下一步发生 `MALFORMED_RESPONSE`，未及时外发查询结果。错误分支未正常清掉判忙状态，也未承接未答消息。旧问题后来由新一轮补答，不能将之前的沉默解释成正常等待。
3. 原 `QQ-PEOPLE.md` 本来确认“柱间＝静”。新桥只注入了名册文件名，没有实际读入人物关系。不能把这个接入漏项解释成正常遗忘。
4. B 站学习的操作计划混进了 QQ 的记忆卡；人设与 B 站同口段、独立风格文件也有重复。已分离操作计划、精简 QQ 不需要的重复段，群聊不再加载主人私信的基金操作说明。

## 最终实现

- 生成格式错误时先清理当前回合的忙碌标记；只对十分钟内尚未答复的来信预留一次有限续接。预留落盘。已有发送、发送结果不确定、在途发送或近期模拟交易变更均不自动续接。401、429、网络错误不触发此恢复，更不会触发 QQ 重登。
- 在现有聊天及关系总纲里合并逻辑检查与熟人相处方式，保留可爱表达、吐槽和主动性。没有加入逐句模板、表情配额或自动道歉脚本。
- 新增仓库外、按稳定账号绑定的已确认人物事实文件。常驻加载四个已核实身份（含柱间＝静）；换会话不衰减。当前昵称变化不会转移到另一个同名账号，未核实的关系不猜着绑定。原名册、聊天和长期记忆保留。
- 关系提示使用内部人物标记，与当前话头对应。已知成员账号如被写进聊天正文，在实际发送前拒绝，要求改用昵称；离线发现的问题没有发送到真实群。
- 两条带旧冲突提示的运行会话已完整备份归档，刷新临时票据，保留群私聊天状态与长期记忆。未升级、重装或重启 QQ 容器与 DSH 主服务。

## 验证及实际边界

服务器 Linux 上52项基金/学习/逻辑/关系检查通过，另外26项耐久发送、21项记忆范围、13项实际桥接虚拟传输检查通过。Windows受限临时目录与回环网络造成的验证失败已按权限边界处理，未据此修改生产持久化逻辑。

实际加载检查：18个安装文件哈希一致；群私均包含柱间与静的关系；群聊不加载基金操作；QQ 不加载 B 站学习操作计划，B 站仍能加载；一篇带来源笔记可读；基金名称查询成功；QQ在线、连接与收件正常。模拟资金仍为1000元，持仓0。

本轮新增模型请求上限合计15次：原生私信验收最多4次，离线对话低档7次、高档对照3次、人物关系核验1次。未连接真实群做模型测试，真实验收只发给主人一条私信。人物测试确实识别柱间就是静，而非只口头说“记住了”。

**软验收仍有不足：**普通问候、名称与人物识别通过；群友反馈冷淡时，多个样本仍有先辩解、补写当时状态的倾向。高思考档没有稳定改善，因此线上保留原低档。不能把传输成功、代码通过或某次顺耳回答写成自然度全部治好，更不能声称训练了权重。后续应围绕这些失败做有边界的评估，不继续往人物卡堆禁令，也不重复运行已完成模型批次。

服务器备份、原始聊天和测试记录只留仓库外。未来开工先核对当前实际人物卡与角色提示，不用历史114卡覆盖。关系文件由运维按已确认资料维护，不能让群友或模型印象改写身份。
