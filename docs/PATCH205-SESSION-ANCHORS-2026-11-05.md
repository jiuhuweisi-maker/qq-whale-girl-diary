# 205：新会话自动加载重要设定

新会话仍从当前人物卡和确认偏好读取身份、语气、表达习惯。偏好文件缺失或空白时，加载源码中的既有表达总纲兜底；已有手写偏好原样保留，权限和其他I/O故障仍会报错。没有另写一套人格或追加逐句禁令。

B站定时和收件唤醒均经统一入口，自动读取主人确认的稳定关系。关系文件仍在私密运行目录，公共代码只包含读取规则。只加载确认事实，使用稳定账号的内部锚点，提醒区分同名账号与跨平台身份对齐。内部回想不等于把名册贴进公开评论。

QQ唤醒已有完整人物上下文时，跳过第二份重复人物卡；完整卡缺失仍保留原有后备入口。具体经历继续按需检索共用日记，没有每轮灌入全部历史。

验证：16个关系/偏好回归、4个B站真实组装函数回归、2个唤醒入口用例，共22个；另检查5个变更运行文件语法。无付费模型调用或测试消息。部署验收用真实配置只读检查三端提示入口、加载版本及文件指纹，不能据此保证长期口吻或每次模型理解均正确。

没有改人物卡原文、关系事实、偏好后缀、图库、概率、模型或发送业务。重载DSH使用既有空闲检查，未重启QQ。
